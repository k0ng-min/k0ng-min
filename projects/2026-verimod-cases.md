# 기여 사례 · VeriMod

[개요](2026-verimod.md) · [내 기여](2026-verimod-contribution.md) · [설계](2026-verimod-design.md)

## 사례 1 — 검증 기술을 기본 화면에 연결

[기본 앱 통합](https://github.com/k0ng-min/2026_blockchain/commit/91477e8)으로 설경민 데모를 기본 사용자 앱으로 가져와 백엔드·프로토콜 계층과 연결했습니다. 사용자는 내부 모듈을 알지 못해도 판정과 Receipt를 한 화면 흐름에서 확인합니다.

## 사례 2 — 실제 입력에서 Receipt 발급

[YouTube 댓글 흐름](https://github.com/k0ng-min/2026_blockchain/commit/3c81893)은 추상적인 테스트 문자열 대신 댓글이라는 실제 입력 맥락에서 발급 과정을 보여 줍니다.

## 사례 3 — 대기 상태를 감추지 않는 앵커

[자동 앵커 구현](https://github.com/k0ng-min/2026_blockchain/commit/39d677e)과 후속 상태 UI 작업은 앵커 전 Receipt를 완료된 블록체인 증명처럼 표현하지 않도록 했습니다.
