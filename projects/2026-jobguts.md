# JOBGUTS · 한국 IT 채용공고 기술 조합 분석

[← 프로필로](../README.md) · [원본 저장소](https://github.com/k0ng-min/2026_bigdata_JobGuts)


## 프로젝트 소개

한국 IT 채용공고에 함께 등장하는 기술을 정규화하고, 직무별 기술 조합과 연관 규칙을 분석하려는 팀 프로젝트 제안입니다.

<a id="evaluation"></a>
## 평가 설계와 결과

채용공고를 거래(transaction), 요구 기술을 항목(item)으로 두고 이름이 다른 동일 기술을 먼저 정규화한 뒤 Apriori·연관규칙 분석을 적용합니다. 결과는 기술 관계 그래프와 관련 역량 추천으로 연결하도록 설계했습니다.

<a id="contribution"></a>
## 내 기여와 팀 구현

**근거 수준: 중간.** 공개 이력상 `k0ng-min` 계정의 2개 커밋으로 제안서와 팀 정보를 관리한 사실은 확인됩니다. 저장소가 제안 단계이므로, 데이터 수집·모형 구현·결과 평가를 완료한 개인 기여로 확대하지 않습니다.

## 대표 기여 사례

- [프로젝트 제안·팀 정보 정리](https://github.com/k0ng-min/2026_bigdata_JobGuts/commit/7c22d92): 분석 대상, 기술 정규화, 연관규칙, 결과 화면의 범위를 README로 명시했습니다.

## 포트폴리오에서 보여줄 역량

분석 전에 데이터 표현·정규화 기준·결과 소비 방식을 먼저 정의한 기획 역량을 보여줍니다. 구현 결과가 추가되면 데이터셋 출처, 전처리 규칙, 지표를 보강할 예정입니다.

<a id="failure"></a>
## 실패 사례와 한계

현재 공개본은 제안·설계 단계입니다. 구현 전이므로 데이터 수집량, 정규화 오류율, 규칙의 지지도·신뢰도, 추천 유용성은 아직 평가 결과로 제시하지 않습니다.
