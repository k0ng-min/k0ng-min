# DangCoffee

[← 프로필로](../README.md) · [원본 저장소](https://github.com/k0ng-min/2022-likelion-DangCoffee)


## 프로젝트 소개

Django 기반 팀 웹 프로젝트입니다. 계정·정보·추천 기능으로 분리된 앱 구조와 템플릿·정적 자산으로 구성돼 있습니다.

<a id="evaluation"></a>
## 평가 설계와 결과

기능을 Django 앱 단위로 분리하고, 검색과 다중 필터처럼 사용자가 목록을 탐색하는 흐름을 화면과 서버 로직으로 연결했습니다.

<a id="contribution"></a>
## 내 기여와 팀 구현

**근거 수준: 중간.** 공개 이력상 `k0ng-min` 계정의 8개 커밋이 확인됩니다. 커밋 메시지에서 검색·다중 필터 작업이 직접 확인되지만, 오래된 팀 저장소라 파일 단위 책임 범위까지 단정하지 않습니다.

## 대표 기여 사례

- [검색 기능 완료](https://github.com/k0ng-min/2022-likelion-DangCoffee/commit/7f583b2): 목록 탐색을 위한 검색 기능 작업을 기록했습니다.
- [다중 필터 구현](https://github.com/k0ng-min/2022-likelion-DangCoffee/commit/3982f30): 조건 조합으로 결과를 좁히는 기능을 시도·개선한 이력이 남아 있습니다.

## 포트폴리오에서 보여줄 역량

초기 팀 프로젝트에서 서버 렌더링 웹의 탐색 경험을 개선하며, 검색·필터 기능을 구현한 출발점으로 기록합니다.

<a id="failure"></a>
## 실패 사례와 한계

공개 이력에는 다중 필터 작업 중 검색이 동작하지 않았던 과정도 남아 있습니다. 기능 완료만 남기지 않고 실패를 기록한 덕분에 검색 조건과 필터 조합을 다시 점검한 개발 과정을 확인할 수 있습니다.
