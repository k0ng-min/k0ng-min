# 근거 기반 여행자보험 전 생애주기 AI

[← 프로필로](../README.md) · [원본 저장소](https://github.com/k0ng-min/2026_finance_ai_challenge) · [라이브 데모](https://travel-insurance-web.onrender.com/)


## 프로젝트 소개

실제 여행자보험 약관을 조항·담보·사고유형·필요서류 단위로 구조화해, 가입 전 비교와 사고 후 청구 준비를 한 흐름으로 지원하는 설명가능 AI 서비스입니다. 근거를 찾지 못한 결과를 숨기지 않고 `확인불가`로 남기는 것을 핵심 원칙으로 둡니다.

## 설계 관점

`원문 약관 → 구조화 데이터 → 결정적 비교 로직 → AI 설명 보조 → 화면의 근거 표시` 순서로 책임을 분리했습니다. 순위 자체는 규칙·가중치로 재현 가능하게 계산하고, LLM은 자유서술 분류와 설명 보조에 한정해 결과의 출처를 추적할 수 있게 설계했습니다.

## 내 기여 평가

**근거 수준: 높음.** 공개 커밋 기록상 `k0ng-min` 계정이 174건을 기여했습니다. 데이터 근거성, 비교 규칙, 사용자 흐름, 보안·운영 문서를 함께 다듬은 통합 기여로 판단했습니다.

## 대표 기여 사례

- [결정적 보험사 순위 설계](https://github.com/k0ng-min/2026_finance_ai_challenge/commit/b501377): Gemini가 순위를 결정하지 않고 설명에만 사용하도록 역할을 분리했습니다.
- [청구지원 E2E 골든셋·안전 평가](https://github.com/k0ng-min/2026_finance_ai_challenge/commit/1134e8c): 결과가 사용자에게 보여지는 흐름을 테스트 가능한 기준으로 만들었습니다.
- [근거가 불완전한 항목의 순위 제외](https://github.com/k0ng-min/2026_finance_ai_challenge/commit/3314a36): 데이터 공백을 긍정 결과처럼 보이게 하지 않는 안전장치를 추가했습니다.

## 포트폴리오에서 보여줄 역량

근거 기반 데이터 모델링, AI의 역할 제한과 검증 설계, 복잡한 도메인 규칙을 사용자 화면의 비교·설명 흐름으로 번역하는 역량을 보여주는 프로젝트입니다.
