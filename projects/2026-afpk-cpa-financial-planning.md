# PlanBridge · CPA 유예생 현금흐름 분석

[← 프로필로](../README.md) · [원본 저장소](https://github.com/k0ng-min/2026-afpk-cpa-financial-planning)


## 프로젝트 소개

CPA 2차 유예생의 합격 발표와 첫 급여 사이 소득 공백을 가상 고객 시나리오로 분석합니다. 18개월 안전자금과 60개월 조건부 가치를 함께 비교해 전업 수험·근로 병행·취업 전환의 조건을 드러냅니다.

<a id="evaluation"></a>
## 평가 설계와 결과

월별 현금흐름, 안전자금 하한, 급여 지연 민감도를 분리해 “장기 지표가 높은 선택”과 “당장 버틸 수 있는 선택”을 혼동하지 않도록 했습니다. 숫자는 Python 재현 코드와 결과 표·SVG에 연결됩니다.

<a id="contribution"></a>
## 내 기여와 팀 구현

**근거 수준: 제한적.** 공개 이력에서 `k0ng-min` 계정의 확인 가능한 커밋은 1건입니다. 해당 커밋은 기존 재무설계 웹 데모를 저장소에 가져와 통합한 작업이며, 재무 모형·결론 전체를 개인 성과로 표기하지 않습니다.

## 대표 기여 사례

- [재무설계 앱 데모 통합](https://github.com/k0ng-min/2026-afpk-cpa-financial-planning/commit/bd5a625): 기존 React·Rust 데모를 프로젝트 저장소에 반영해 실행 가능한 데모 층을 연결했습니다.

## 포트폴리오에서 보여줄 역량

협업 산출물을 단순 복사하지 않고, 재현 가능한 분석 모형과 별도 데모의 경계를 문서화해 통합하는 태도를 보여줍니다. 상세한 재무 판단은 팀 산출물이며, 개인 기여 범위는 위 통합 작업으로 한정합니다.

<a id="failure"></a>
## 실패 사례와 한계

가상 고객·가정값으로 만든 비교이므로 실제 합격·채용·급여를 예측하지 않습니다. 웹 데모와 참조 모형은 전제와 숫자가 다를 수 있으므로, 화면의 결과를 분석 모형의 독립 검증으로 해석하지 않습니다.
